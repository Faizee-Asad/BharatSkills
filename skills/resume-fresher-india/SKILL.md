# Resume Fresher India

For Indian students and fresh graduates applying for their first job or internship —
through job portals (Naukri, LinkedIn, Internshala, Indeed), campus placement, or
walk-in / direct applications.

## When to use this skill
- "Resume banana hai" / "Fresher ka CV kaise banau?"
- "Mera resume hai par koi reply nahi aata" (resume gets no responses)
- "Career objective kya likhu?" / "Projects kaise dikhau bina experience ke?"
- "Naukri par profile ka headline kya rakhu?"

## What you need from the user
- Name, city, and the role they are applying for
- Education: latest degree first — course, college/university, year, marks (% or CGPA)
- Internships, training, or part-time work (if any)
- Projects (college, personal, freelance — anything real they built or did)
- Technical/ job skills they can honestly demonstrate
- Certifications, achievements, languages known

Never put Aadhaar, PAN, full home address or date of birth on a resume that will be
uploaded to portals and forwarded around. Name, city, mobile and email are enough —
extra personal details belong on the employer's joining form, not the resume.

## The structure (one page for freshers)

1. **Header** — Name (big), city, mobile, professional email, LinkedIn / GitHub /
   portfolio link if relevant to the role.
2. **Career objective** — 2–3 lines, written for *this* role (see rules below).
3. **Education** — latest first. Degree, institution, board/university, passing year,
   marks. Include Class 12 and 10 only if marks are decent or the job asks; drop them
   once you have work experience.
4. **Internships / Training** — company, duration, what you actually did (verbs +
   results, not "worked as intern").
5. **Projects** — for freshers this section matters more than anything else. Each
   project: title, 2–3 lines on what it does, tools used, and a link if it is live.
6. **Skills** — grouped (e.g. Languages / Tools / Office), only what you can answer
   questions about in an interview.
7. **Certifications & Achievements** — courses, olympiads, sports, NSS/NCC, anything
   verifiable.
8. **Declaration** (optional) — "I hereby declare that the above information is true…"
   is still common on Indian fresher resumes and some employers' formats expect it.
   Include it for traditional companies / walk-ins; it can be dropped for startups
   and MNC portal applications.

## Workflow

### 1. Start from the job, not from a template
Read the job description (JD) first. Note the 5–8 keywords it repeats (skills, tools,
qualities) and make sure the true ones appear in the resume — portal search and ATS
software match on these words.

### 2. Write the objective for this role
Bad (copy-paste, says nothing):
> "To work in a reputed organisation where I can utilise my skills for the growth of
> the organisation and myself."

Better (specific, honest):
> "B.Com graduate (2025) with Tally Prime and GST coursework and a 2-month accounts
> internship, seeking an entry-level accounts role in Malegaon/Nashik. Comfortable
> with Excel, data entry and invoice preparation."

Formula: **qualification + strongest 1–2 proofs + role you want (+ location if fixed)**.

### 3. Turn duties into proof
- Weak: "Did a project on online shopping website."
- Strong: "Built a working e-commerce website as final-year project (PHP + MySQL):
  product listing, cart and order form; demonstrated to a panel of 40 students."
Use numbers wherever honest: marks, users, days, amounts, rank.

### 4. Format for both humans and software
- One page, simple single-column layout, standard fonts (Calibri/Arial), PDF format.
- No photo, tables, or text boxes for portal/ATS applications — software reads them
  badly. (A photo version is still common for local walk-in applications in India;
  keep two versions if needed.)
- File name: `FirstName-LastName-Resume.pdf` — not `resume_final_v3.pdf`.
- Spell-check, then read it aloud once — most fresher resumes have 3–4 typos.

### 5. Mirror it on the portals
- Naukri/LinkedIn headline = role + top skill, e.g. "Fresher Accountant | Tally Prime,
  GST, Excel" — recruiters search by headline.
- Keep the portal profile and the resume consistent (same dates, same marks).

## Template (structure)

```
<FULL NAME>
<City, State> | <Mobile> | <Email> | <LinkedIn/GitHub link>

CAREER OBJECTIVE
<2–3 lines written for this specific role — qualification + proof + role wanted>

EDUCATION
<Degree>, <College>, <University> — <Year> — <Marks/CGPA>
<Degree>, <School/College>, <Board> — <Year> — <Marks>

INTERNSHIPS / TRAINING
<Role>, <Company>, <Duration>
- <What you did, with a result or number>

PROJECTS
<Project Title> — <Tools used>
- <What it does, in 2 lines; link if live>

SKILLS
<Skill group 1>: <skills>   |   <Skill group 2>: <skills>

CERTIFICATIONS & ACHIEVEMENTS
- <Item, year>

DECLARATION (optional)
I hereby declare that the above information is true to the best of my knowledge.
<Place>                                            <Name / Signature>
```

## Rules & common mistakes
- ❌ One common resume blasted to every job — tailor the objective and skills order to each JD.
- ❌ Copy-paste objectives and "Hobbies: listening to music, playing cricket" filler — recruiters spot these instantly.
- ❌ Claiming skills you cannot demonstrate — the interview will test the first skill on the list.
- ❌ 3–4 page resumes for freshers — one page forces you to keep only what matters.
- ❌ Putting Aadhaar/PAN numbers, full home address, or parents' details on a resume sent to portals and strangers.
- ❌ Marks hidden or inflated — companies verify against mark sheets at joining; a mismatch ends the offer.
- ✅ No experience is normal for a fresher — projects, internships, and part-time/family-business work are real proof. Present them well instead of apologising for them.
- ✅ This skill helps with format and presentation only — it cannot promise a job or interview. Say this clearly if the user asks.
