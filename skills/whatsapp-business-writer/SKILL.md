# WhatsApp Business Writer

For Indian shops, salons, tutors, clinics, agencies and online sellers who talk to
customers on WhatsApp all day. Produces short, warm, ready-to-send messages —
not long formal emails squeezed into a chat.

## When to use this skill
- "Customer ne price pucha hai, reply likho"
- "WhatsApp par offer bhejna hai" / festival sale announcement
- "Order dispatch / delivery ka message" 
- "Appointment confirm karna hai", "review mangna hai", "purane customer ko follow-up"

## What you need from the user
- Situation (what happened / what the customer asked)
- Business name and one key detail (price, date, offer, timing)
- Language choice: English / Hinglish / Hindi — if unsure, match the customer's language
- Tone: normal friendly is default; formal only for complaints

Never include any customer's phone number, address or other personal data in a
template example. Use placeholders like <Name>.

## WhatsApp style rules (India)
1. **Short.** 2–5 lines per message. Long paragraphs don't get read on WhatsApp.
2. **Start with the customer's name + Namaste/Hi** — it raises replies.
3. **One message, one purpose.** Price + offer + address in one message = confusion.
4. **End with a clear next step** — "Order confirm karu?", "Kal 11 baje aa jaiyega?"
5. **Emojis: 0–2, purposeful** (🙏 ✅ 🚚). Never a wall of emojis in a business message.
6. **Business hours matter** — broadcasts between 10am–8pm IST; never late night.

## Templates

### Price enquiry reply (Hinglish)
```
Namaste <Name> ji 🙏 <Item> ki price ₹<Price> hai.
Home delivery is area me free hai. Order confirm karu?
— <Business Name>
```

### Festival offer broadcast (English + Hinglish line)
```
🎉 <Festival> Special at <Business Name>!
Flat <X>% off on <Category>, sirf <Dates> tak.
Visit karein ya WhatsApp par order karein: <Number/Link>
T&C apply. — Team <Business Name>
```
Broadcast rule: only message customers who bought from / opted in to the business.
Unsolicited bulk messaging gets numbers reported and banned — say this if asked.

### Order update — dispatched (English)
```
Hi <Name>, your order <Order No.> is dispatched 🚚
It should reach you by <Date>. Tracking: <Link>
Koi dikkat ho to isi number par reply karein. — <Business Name>
```

### Appointment confirmation (Hindi)
```
Namaste <Name> ji, aapki appointment pakki hai ✅
Tarikh: <Date>, Samay: <Time>, Jagah: <Place>
Der ho to pehle bata dijiyega. — <Business Name>
```

### Complaint reply — cool and professional (English)
```
Namaste <Name> ji, takleef ke liye maafi chahte hain 🙏
Aapki baat samajh aa gayi hai — <issue in one line>.
Hum <solution> kar rahe hain, <time> tak update milega.
— <Name>, <Business Name>
```
Never argue with a customer in chat, never blame them, always give a time for the next update.

### Review request (after delivery/service)
```
Namaste <Name> ji, <Item/Service> kaisa laga?
Ek chhoti si review milegi to bahut madad hogi: <Google Review Link>
Dhanyavaad! 🙏 — <Business Name>
```

### Dormant customer follow-up (15–30 days later)
```
Namaste <Name> ji, kaafi din ho gaye!
<New item/offer line — one line only>
Chahiye to ghar baithe order kar sakte hain. — <Business Name>
```

## Rules & common mistakes
- ❌ Don't write email-style "Dear Sir/Madam, With reference to the above subject…" on WhatsApp.
- ❌ Don't send broadcasts to purchased/scraped number lists — spam reports can get the business number banned.
- ❌ Don't promise delivery dates, discounts or refunds the business hasn't approved.
- ✅ Mirror the customer's language — Hindi customer → Hindi/Hinglish reply.
- ✅ Save good replies as WhatsApp Quick Replies / catalogue messages so staff reply consistently.
